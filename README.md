# 🎓 بوابة فرز مفاضلة الفرع العلمي في سوريا

موقع إلكتروني ذكي ومطور بلغة بايثون للتنبؤ بالكليات والجامعات السورية المتاحة للطلاب بناءً على مجموعهم المئوي الصافي لعام 2026/2027.

## 💻 المطور والمهندس المسؤول
* **إعداد وتصميم:** المبرمج محمد القاسم

## 🚀 ميزات النظام
* **تحليل تلقائي دقيق:** فحص المجموع ومقارنته بالحدود الدنيا للفرع العلمي.
* **دعم أنواع المفاضلة:** فرز مخصص للمفاضلة العامة والتعليم الموازي.
* **واجهة حديثة ومتجاوبة:** تصميم باللون الزيتي الفخم متوافق بالكامل مع الهواتف.
* **حفظ البيانات تلقائياً:** تخزين رغبات ومعدلات الطلاب في ملف Excel خلفي (`mofadala_history.xlsx`).

## 🛠️ التقنيات المستخدمة
* **Backend:** Python (Flask)
* **Frontend:** HTML5, CSS3 (Tajawal Font)
* **Data Management:** Pandas, OpenPyXL (Excel)
* **Deployment Tunnel:** Ngrok

## 📋 طريقة التشغيل للمطورين

### 1. تثبيت المكتبات اللازمة:
```cmd
pip install flask pandas openpyxl
```

### 2. تشغيل سيرفر البايثون:
```cmd
python app.py
```

### 3. فتح النفق العام عبر Ngrok:
```cmd
ngrok http 5000
```
